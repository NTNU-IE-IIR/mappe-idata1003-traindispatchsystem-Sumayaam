## Project description

[//]: This project is a small application of a train Dispatch System taking one train station into account. It is testing our ability to apply and use the theory that we have undergone during this semester,
while making the application efficient and user-friendly. The code should be robust and cannot crash in any form. The application should display what all train system displays, departure times, delays, and destinations. 
The operator of the system should not feel restricted in any way, and should be able to add, remove, and edit departures as they see fit. Whilst following these criteria i have created a project that is easy to use, and fun!
Take note that the code contains a lot more comments and Java docs than what is usual, this is because i wanted to make sure that my solutions came through clearly, and it is created because of an exam situation. 

[//]: For this application to work properly i have created 5 classes, and 3 packages.The classes i have created are TrainDeparture and TrainStationClock which is under the entity package, TrainDispatchRecord which is under logic, and TrainDispatchAppUi under the Ui package, and we also have a class which starts the application called TrainDispatchApp.
The TrainDeparture class contains information that is needed to create a train Departure. The TrainDispatchRecord class tackles the logic of the train departures. The TrainStationClock class is the clock of the train station, and the TrainDispatchUi is the user interface of the application. The TrainDispatchApp starts the application.
The classes in the entity and logic package each have a test. These tests are located in the test folder, and are named TrainDepartureTest and TrainDispatchRecordTest, and TrainStationClockTest. The Ui package does not have a test, as it is tested through the user interface when running the program.
All the classes and packages are documented with Java docs, and the code is commented to make it easier to understand. They are also under teh source file which is under the directory structure of src/main/java, and the test files are under src/test/java.

## How to run the project

To run the project, go to TrainDispatchApp and run the main method. This will get the application going, and a menu with options will appear, where the user can chose between a variety of options. The menu will show with a number followed by an option.
The menu loops until the user exits, by entering the number to exist.

## How to run the tests
Navigate to the test folder, and open the test class u want to run. Then simply press the run button at the top of the class, or for each individual test. And that's it!
